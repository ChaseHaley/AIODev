AIODev is a terminal emulator currently targeting Windows 11 making use of libghostty-vt and ConPTY. This is very early access, and *heavily* vibe coded with slop slowly being cleaned up alongside new features and bug fixes. This project exists because other Windows terminals did not provide the UX I want in a modern terminal. Heavily inspired by Rex (_without the multiplexing_) and Vivaldi, the browser.
